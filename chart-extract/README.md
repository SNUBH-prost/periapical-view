# 차트 내용 → 엑셀 항목 자동 채우기

엑셀에 있는 **차트 내용(텍스트) 열**을 읽어서, 임플란트·당화혈색소(HbA1c)·ISQ 같은
연구 항목을 **규칙(키워드/패턴)으로 찾아** 같은 엑셀의 빈 열에 채워 넣는 도구입니다.

- **인터넷이 필요 없습니다.** (클라우드 AI 안 씀 — 내부망 PC에서 그대로 실행)
- 원본 엑셀은 건드리지 않고 `_결과.xlsx` 로 새로 저장합니다(설정으로 변경 가능).
- 규칙은 `src/rules.py` 에서 직접 고칠 수 있습니다.

---

## 준비: 엑셀 만들기

첫 줄(제목행)에 아래처럼 열을 두고, **`차트내용` 열에 차트 텍스트를 붙여넣기**만 하면 됩니다.
나머지 항목 열은 비워두세요. 프로그램이 채웁니다.

| 환자번호 | 차트내용 | 나이 | 성별 | 임플란트 회사 | ... |
|---------|---------|------|------|--------------|-----|
| 0000000 | (차트 전체 텍스트) |  |  |  | ... |

> 열 제목은 `config.yaml` 의 이름과 같아야 합니다. 제목 앞뒤 공백은 자동 무시합니다.

---

## 실행

```
run.bat "C:\경로\환자목록.xlsx"
```

먼저 점검만 하려면(엑셀 안 건드림):

```
run.bat "C:\경로\환자목록.xlsx" --check
```

끝나면 같은 폴더에 `환자목록_결과.xlsx` 가 생깁니다.

---

## 설치 (인터넷 되는 PC → USB → 내부망 PC)

**인터넷 되는 PC에서** 패키지를 USB로 내려받기:

```
pip download -r requirements.txt -d wheels
```

USB에 이 폴더 전체(+`wheels`)를 복사한 뒤, **내부망 PC에서**:

```
pip install --no-index --find-links wheels -r requirements.txt
```

> Python 자체 설치가 필요하면 옆 폴더(Infinitt 도구)의 `usb_준비 / usb_설치` 방식과 동일합니다.

## 규칙 고치기 (제일 중요)

`src/rules.py` 안의 함수가 각 항목을 어떻게 찾는지 정합니다.
지금 들어있는 패턴은 **흔한 형태를 가정한 예시**라서, 실제 차트 문장을 보고
정규식만 바꿔주면 정확도가 올라갑니다.

예) 회사명을 추가하려면 `_COMPANIES` 사전에 한 줄 추가:

```python
r"내가쓰는표기|영문표기": "화면에 넣을 이름",
```

`config.yaml` 에서는 어떤 열을 채울지, 이미 값이 있으면 덮어쓸지(`overwrite`),
원본에 바로 채울지(`in_place`) 등을 조절합니다.
