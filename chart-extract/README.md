# 차트 노트 → 임플란트 정리표 자동 추출

외래경과 노트가 **한 줄에 하나씩** 들어있는 엑셀을 읽어서,
**임플란트(치아) 한 개당 한 줄**로 정리한 새 엑셀을 만들어 줍니다.

- **인터넷 필요 없음** (클라우드 AI 안 씀 — 내부망 PC에서 그대로 실행)
- **원본 엑셀은 건드리지 않고** `입력_결과.xlsx` 새 파일로 저장
- 환자별로 모든 노트를 모아, 치아번호(#15i 등)로 묶어서:
  - **식립기록**(`Implant installation`)에서 → 부위 · 규격(직경·길이) · 골이식 · 식립일 · 회사
  - **나중 보철 노트**에서 → ISQ (협/설/평균)
  를 연결합니다. **식립기록이 있는 임플란트만** 표에 넣습니다.

---

## 입력 엑셀 모양

붙여주신 그대로면 됩니다. 첫 줄은 제목, 그 아래로 노트가 한 줄씩:

| Serial No. | 환자번호 | 나이 | 생년월일 | 성별 | 노트번호 | 내용 |
|-----------|---------|------|---------|------|---------|------|
| 1 | 0000000 | 81 | ... | 여 | 44220026 | ■ 외래경과 ... (노트 전체) |
| 1 | 0000000 | 81 | ... | 여 | 30613671 | ■ 외래경과 ... |

- 환자번호·나이·생년월일·성별 열은 **제목으로 자동 인식**합니다.
- **노트 본문 열은 자동으로 찾습니다** (글자가 가장 긴 열).

---

## 실행

```
run.bat "C:\경로\입력.xlsx"
```

먼저 읽기만 점검(쓰지 않음):

```
run.bat "C:\경로\입력.xlsx" --check
```

끝나면 같은 폴더에 `입력_결과.xlsx` 가 생깁니다.

### 결과 열
Serial · 환자번호 · 나이 · 생년월일 · 성별 · 식립 부위(상악/하악) · 식립일 · 회사 ·
직경 · 길이 · 골이식(Y/N) · **당화혈색소 5칸(비움 — 아래 참고)** · ISQ 협/설/평균

그리고 **확인용 보조 열** 4개(치식 · ISQ원본 · ISQ측정일 · 식립노트일)가 뒤에 붙습니다.
값이 맞는지 눈으로 대조하기 위한 것이니, 확인 후 지우셔도 됩니다.

---

## 당화혈색소(HbA1c)

외래경과 노트에는 HbA1c가 없어서 **5개 열은 비워둡니다.**
검사결과(Lab) 엑셀을 주시면 **환자번호 + 날짜**로 연결해 채우는 단계를 추가하겠습니다.

---

## 설치 (인터넷 되는 PC → USB → 내부망 PC)

인터넷 되는 PC에서:
```
pip download -r requirements.txt -d wheels
```
USB로 이 폴더 전체(+`wheels`)를 옮긴 뒤, 내부망 PC에서:
```
pip install --no-index --find-links wheels -r requirements.txt
```

## 규칙 고치기 (제일 중요)

실제 차트 표기가 예시와 다르면 `src/parse.py` 안의 정규식/사전만 고치면 됩니다.

- **회사/제품명**: `BRANDS` 사전에 한 줄 추가 — `"내표기": "출력이름",`
- **식립 인식**: `is_installation_note` (지금은 `Implant installation` / `임플란트 식립`)
- **규격**: `_SPEC` (지금은 `4.0 mm X 10mm` 형태)
- **골이식**: `_GBR_POS`
- **ISQ**: `find_isq` — `ISQ` 라벨 아래 줄만 읽고, 30~99 범위만 인정해
  조직두께(`4/4/5/4`)와 혼동하지 않습니다.

바꾼 뒤 `python -m tests.test_parse` 로 검증할 수 있습니다.

---

## 판단 규칙 (지금 설정)

- **ISQ 순서**: 앞=협(buccal), 뒤=설(lingual). 예 `80/77` → 협 80, 설 77.
- **여러 번 측정된 ISQ**: 식립일 **이후 가장 이른** 측정을 사용 (설치노트에 ISQ가 있으면 그 값).
  선택된 값과 측정일은 보조 열에서 확인 가능합니다.
- **대상**: 이 데이터 안에 `Implant installation` 기록이 있는 임플란트만.
